# Daily search and publishing

Read companies.json for the complete 403-company target list. Search Software Engineer, Full-stack Developer/Engineer, Java Developer and React Developer roles. Prioritise Germany, Netherlands and Ireland; consider UK, Sweden, Denmark, Switzerland, Canada and Australia. Use the candidate preferences supplied privately to the scheduled task. Do not commit a personal candidate profile.

Also search official Indian government/PSU recruitment sources for CSE/IT degree opportunities. Do not assume age, category certificate, GATE or experience eligibility. Record precise requirements and deadlines in job notes and authorisation fields.

Read docs/jobs.json and preserve prior entries. Upsert by stable company + exact requisition ID. Use only company-owned direct career pages. Exclude Workday, Ashby, Greenhouse, Lever, SmartRecruiters, aggregators and external redirects. Include new discoveries only when an explicit posting date is within seven days; do not infer dates from crawl time, first-seen time or article dates. Only mark Verified current after opening the official vacancy page and confirming it is active. Store official URL, exact ID, evidence and checked timestamp. Confirmed sponsorship requires explicit official evidence and its URL; sponsor-register status alone is insufficient. Mark closed only after explicit official evidence; inaccessible is Unverified, not closed.

Public feed schema: {jobs:[{id,company,country,role,salary,location,experience,skills,authorisation,jobId,officialUrl,listingUrl,postedAt,verifiedAt,evidence,sponsorshipEvidence,sponsorshipUrl,sponsorship,source,verification,fit,gaps,notes}],runs:[{at,checkedCompanies,checkedCount,targetCount,blockedCompanies,notCheckedCount,summary}],updatedAt}. Sponsorship values: Confirmed, Uncertain, Not offered. Source: Official career page or Third-party listing. Verification: Verified current, Unverified, Closed. Fit: Strong fit, Partial fit, Low fit, Not assessed.

Append an honest coverage record every run, including blocked and unfinished checks. Keep the latest 100 runs. Never claim all 403 companies checked unless each was checked. Government coverage must be recorded separately.

Update docs/jobs.json through GitHub fetch_file + update_file using the returned current blob SHA. You may also expand collector-sources.json after verifying that each approved hostname is owned by the named target company or official government organisation; use exact hosts and direct careers/recruitment URLs. Preserve all existing sources and deduplicate company + URL. Never approve ATS or aggregator hosts. Retry a rejected update only after refetching and merging. Fetch each written file to verify persistence. The Railway backend merges the public research feed with its private Apify collector results. Routine feed changes need no app rebuild. Private application status, dates, referral contacts, interview stage, skill gaps and notes must never be committed to this public repository. See APIFY_SETUP.md for bounded daily crawl behaviour and partial-coverage limits.
